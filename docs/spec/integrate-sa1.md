The integrated registry installs PROGRAMME, SAP, CALLFLOW, DISTRIBUTOR and TPM. SAP installs its server-only environment before partner requests execute. Integrated partner credit uses the SAP gateway; the older sample reference adapter is retained only for isolated domain fixtures where the SAP installer is absent. Partner PO acknowledgement is asynchronous; an absent SAP-promised delivery date stays unknown rather than being fabricated by the web app. Sample instructions are refused when enqueued against real SAP.

The basic company CLI adds the separately owned distributor namespace only with `--distributors`. This preserves the base seed/reset contract; `--reset --distributors` is refused. Distributor samples can be added independently and idempotently. A core-only reset still refuses outside dependencies, including separately owned partner rows.

Additive migration `0405_sap_sample_trace_reset.sql` permits trace deletion only during the explicit sample-reset transaction when both exact child and parent ownership markers exist. Normal trace mutations, unowned operator actions and conflict history remain append-only. No live reset is required or permitted for this deployment.

A cold-reset regression also exposed missing bulk-table planner statistics and unnecessary whole-row JSON conversion in dependency checks. Reset now analyzes the locked tables, uses direct UUID identity joins where the catalog proves the type, and bounds hash-join working memory at 64 MB for that transaction. Ownership, foreign-key, append-only and outside-reference checks are unchanged; the original 180-second CLI regression remains the acceptance bound.
