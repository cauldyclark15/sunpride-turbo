# SFA glossary

Canonical vocabulary for coverage, visits, and van sales. **These definitions are proposals pending business sign-off** — they are derived from the tracker's own usage and the reference SFA workflow, and must be confirmed against Sunpride's current process before any metric is implemented (`ARCH-003`, `ARCH-008`, `ANA-001`).

Rewrite the "Definition" column with Sunpride's words. Where Sunpride uses a different term for the same idea, add it under "Also called", and use the agreed term everywhere afterwards — the tracker already treats this vocabulary as a gate (`ARCH-008`).

| Term                 | Definition (pending sign-off)                                                                                                                                                            | Also called            | Used by               |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | --------------------- |
| Organization unit    | A node in the configurable sales hierarchy (national, region, area, territory levels are data, not fixed names).                                                                         | Org unit, scope        | ADR-005, `WEB-002`    |
| Team                 | A group of employees reporting to one supervisor within an organization unit.                                                                                                            | Squad, group           | `CVX-004`             |
| Employee             | A person who executes or supervises field work; in Turbo this is a user profile with a role and an organizational scope.                                                                 | Salesperson, agent     | `CVX-004`             |
| Territory            | A defined area of selling responsibility, owned by an organization unit, optionally bounded by a polygon.                                                                                | Area, patch            | `CVX-005`             |
| Route / beat         | An ordered set of outlets served on a repeating schedule within a territory.                                                                                                             | Beat, itinerary        | `CVX-006`             |
| Outlet               | The physical place where selling, merchandising, or delivery happens, with its own location, geofence, and visit frequency.                                                              | Store, account         | `CVX-007`             |
| Customer             | The accounting entity that is invoiced; SAP-authoritative, and linked to one or more outlets.                                                                                            | Account, ship-to       | `ARCH-010`, `SAP-004` |
| Master Coverage Plan | The approved, versioned plan stating which outlets are visited, how often, on which days, by which employee.                                                                             | MCP, call plan         | `CVX-008`, `WEB-009`  |
| Planned call         | A visit the active coverage plan requires on a specific date for a specific outlet.                                                                                                      | Planned visit          | `CVX-011`             |
| Actual call          | A visit that was actually executed and recorded, whether planned or unplanned.                                                                                                           | Executed call          | `CVX-012`             |
| Productive call      | An executed call that produced a business outcome the business counts as productive (an order, a collection, or a verified merchandising result — **the deciding rule needs sign-off**). | Effective call         | `ANA-001`             |
| Strike rate          | Productive calls divided by planned calls for a scope and period. Size and definition need sign-off before use.                                                                          | Hit rate               | `ANA-001`             |
| Coverage             | Share of assigned outlets actually visited in the period, by scope.                                                                                                                      | Call coverage          | `ANA-008`             |
| Visit intent         | The declared purpose of a visit — sell, collect, merchandise, audit, deliver, promotion, complaint, follow-up.                                                                           | Call objective         | `ARCH-014`            |
| Visit                | One outlet interaction: arrival, check-in, activities, checkout, result, with location evidence and lifecycle timestamps.                                                                | Call                   | `ARCH-013`, `CVX-012` |
| Trip                 | One van's operational journey: load, selling, reconciliation, close.                                                                                                                     | Route run, route       | `CVX-027`             |
| Truck load           | The approved quantity by product, unit, and lot placed into a vehicle at the start of a trip.                                                                                            | Load-out               | `CVX-028`             |
| Van sale             | A sale executed from a vehicle's stock, posted as a stock movement from the truck location.                                                                                              | POS sale               | `VAN-011`             |
| Reconciliation       | The governed comparison of expected versus counted stock, or Turbo versus SAP quantities, producing reviewed differences.                                                                | Recount, variance      | `VAN-023`, `SAP-015`  |
| Opening stock        | The approved starting quantity by product, location, and lot, posted once as an opening-balance movement at cutover.                                                                     | Cutover balance        | `SFD-014`, ADR-007    |
| App role             | A code-owned permission set (`super_admin`, `admin`, `operations`, `manager`, `approver`, `sales`, `analyst`, `viewer`). Never a job title.                                              | Access role, user type | ADR-009               |
| Position             | A Sunpride job title as data (`positions`), carrying the client's standards in `positionStandards`.                                                                                      | Job title, designation | ADR-009               |
| Employment type      | How a person relates to Sunpride: `sfi_employee`, `adp_personnel` (a third party Sunpride supervises), or `third_party`.                                                                 | —                      | ADR-009               |
| Channel scope        | The selling channel a person works (`KA`, `GT`, `PMOT`); an attribute, not a role, because one CDM title spans channels.                                                                 | Segment                | ADR-009               |
| Persona              | Role + position + organizational scope. The unit a screen or endpoint is designed for.                                                                                                   | User type              | ADR-009               |
