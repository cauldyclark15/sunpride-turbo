04 · Access

The phone apps

For now, the apps come from a shared Google Drive folder, not the Play Store.

  1. Open the sunpride_apps Drive link we'll send you in Messages
  2. Download Field (sales agents) or Van Sales (van sellers)
  3. Allow the install when Android asks
  4. Sign in with your Sunpride account
04 · Updates

When a new version is ready

  • "System" sends you a message with the download link
  • The app shows an Update available bar
  • Download it and install it over the current app. Your saved work stays.
  • Settings shows your installed and latest versions
05 · Issues

A small group files the issues.

Who

A few named people from Sunpride, so reports stay clear and nothing is duplicated. Everyone else tells them, or posts in Messages.

Where

The Issues page in the web app. One place for every report.

What to include

What you did, what you expected, what happened, and a screenshot.

After a fix

It comes back as Ready for retest. Mark it Done, or comment if it's still broken.

06 · How we work

Short loops, fast fixes.

  1. You use the apps on real work
  2. You report it as an issue or in Messages
  3. We fix it and ship it to the same web address or a new app version
  4. You retest, then confirm or comment

Questions come both ways. We'll ask in comments when we need detail.
