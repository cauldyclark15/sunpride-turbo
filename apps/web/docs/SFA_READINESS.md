# WEB-001 — SFA management web readiness

## Verdict

**Yes — extend the existing shell, not a parallel admin.** The authenticated dashboard layout already wraps a single `OperationsShell` and routes modules through `ModuleWorkspace`; navigation has Field Sales, Approvals, Reports and Administration entry points (`apps/web/src/app/(dashboard)/layout.tsx:7-18`; `apps/web/src/app/(dashboard)/[module]/page.tsx:6-13`; `apps/web/src/config/navigation.ts:17-67`). This fits the management web's plan/assign/monitor/approve/analyze remit (`docs/decisions/ADR-010-NATIVE-FIELD-APPS-IOS-AND-ANDROID.md:15-22`). It is a **structural** yes, not an authorization or feature-completeness sign-off: Field Sales currently renders placeholder cards, while the admin screen handles invitations/persona assignment rather than hierarchy and teams (`apps/web/src/components/module-workspace.tsx:472-523`; `apps/web/src/components/admin-workspace.tsx:41-63,173-247,250-419`). Runtime behavior and deployed access are **UNVERIFIED**; this is source review only.

## Risks

- UI role literals can drift from server capabilities; centralize UI capability-derived affordances, but keep Convex authorization authoritative (`apps/web/src/components/operations-shell.tsx:15-18`; `apps/web/src/components/admin-workspace.tsx:41-63`; `packages/backend/convex/lib/capabilities.ts:22-78,104-125`).
- Hidden navigation is not a route guard: the generic `[module]` route renders `AdminWorkspace` on direct `/admin` visits, where its own role check applies; unknown module slugs fall back to the dashboard (`apps/web/src/app/(dashboard)/[module]/page.tsx:6-13`; `apps/web/src/components/module-workspace.tsx:123-126,472-473`; `apps/web/src/components/admin-workspace.tsx:75-87`). Add explicit module-level access/unknown-route behavior; never rely on hiding links.
- `ModuleWorkspace` calls `seedDemo()` on initialization; assess/remove this side effect before production SFA screens share that entry path (`apps/web/src/components/module-workspace.tsx:127-148`). The Mobile/PWA tab and description conflict with the native-field-app decision and should be retired or renamed (`apps/web/src/config/navigation.ts:63-66`; `apps/web/src/components/module-workspace.tsx:53-58`; `docs/decisions/ADR-010-NATIVE-FIELD-APPS-IOS-AND-ANDROID.md:15-30`).
